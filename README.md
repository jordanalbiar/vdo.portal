## VDO Portal
A single-file, no-install browser workspace for producing, joining, and watching VDO.Ninja sessions, with role-based portals, a floating window canvas, live custom backgrounds, and full layout control.

## What Is This?
VDO Portal is a self-contained HTML application that wraps VDO.Ninja. A free, open-source, peer-to-peer video platform, inside a polished, purpose-built interface. Rather than juggling multiple browser tabs or memorizing long VDO.Ninja URLs and parameter strings, VDO Portal gives you a single launchpad that handles everything: room setup, role selection, URL construction, window layout, and session customization.
The entire application lives in one HTML file. There is no server, no database, no npm install, no build step, no account, and no subscription. You open it in a browser and it works. You can host it anywhere static files are served — GitHub Pages, Netlify, Cloudflare Pages, an S3 bucket, a local file, or even a USB drive.

## Features
Three Role-Based Portals
VDO Portal opens differently depending on which role you select at the intro screen. Each role has its own color identity that carries through the entire UI, from the intro card glow to the workspace bars to every window border.

![VDO Portal Screenshot](https://github.com/jordanalbiar/vdo.portal/blob/main/Screenshot_20260526_225348.png?raw=true))

# 🟣 Host / Director — Purple
Opens the Director control panel, your personal broadcast window, the scene output, a mixer panel, and a chat window. This is the full production suite. As the host you can see and manage everyone connected to the room, arrange them in the mixer, and control what the scene output shows to viewers. The welcome guide explains each panel in plain terms for people who are new to VDO.Ninja.

# 🔵 Guest — Blue
Opens your broadcast window (your camera), the room scene, the mixer scene, and chat. Guests are participants in the call. Their broadcast link is automatically generated with your room name and display name, and the scene window shows you everything happening in the room.

# 🟢 Viewer — Green
Opens only the scene output, maximized to fill the canvas. Viewers watch the broadcast without joining as participants. No camera, no microphone, no presence in the director panel, just the output.

## Getting Started

![VDO Portal Screenshot](https://github.com/jordanalbiar/vdo.portal/blob/main/Screenshot_20260526_225245.png?raw=true)

### Step 1 — Open the file
Download the HTML file and open it in Chrome or Edge. No installation. No account. Just open it.

> Chrome and Edge are recommended because VDO.Ninja works best in Chromium-based browsers.

### Step 2 — Read the privacy notice
A short plain-language summary explains how VDO.Ninja works: your video goes directly to the people you call (peer-to-peer, like a phone call), nothing is recorded, and your room name is your key, treat it like a password. Click to continue.

### Step 3 — Choose your role
Pick **Host**, **Guest**, or **Viewer** depending on what you are doing. The card changes color to match. If you are not sure, Host is for running a room, Guest is for joining one, and Viewer is for watching one.

### Step 4 — Fill in your details
- **Room Name** — make something up, or use one someone gave you. Everyone who enters the same room name on the same server ends up in the same session.
- **Your Name** — how you appear to others in the room. Letters only.
- **Password** — optional but recommended if your room is private. Everyone joining must use the same password.

### Step 5 — Launch
Click the button. Your workspace opens. A welcome guide appears explaining what each window does. You are live.

## Sharing a Room With Others

There is no shareable link generated by VDO Portal itself, the room lives in VDO.Ninja, not in the portal. To invite someone:

1. Tell them your **room name** and **password** (if you set one)
2. Send them a link to your hosted copy of VDO Portal (or the file itself)
3. Tell them which role to pick. Guest if they are joining the call, Viewer if they are just watching

That is it. No account creation, no email verification, no app download required on their end either.

## VDO.Ninja Parameter Toolbars

Each window exposes a curated set of VDO.Ninja URL parameters as toggle buttons inside a collapsible toolbar. No need to know the parameter names. For the broadcast window these include things like Pro Audio mode, 1080p60 video, virtual backgrounds, screenshare button, audio compressor, mute controls, and more. For scene windows they include layout options like cover crop, portrait mode, fade-in, label display, and codec selection. Toggling a parameter instantly reloads the iframe with the updated URL.

## Custom Background System
A built-in code editor lets you inject a custom animated HTML/CSS/JavaScript background directly into the VDO.Ninja scene iframe. The background layer is injected at the iframe level, not as a page overlay, so it appears as an actual background behind the video feeds in the output.
The editor has three panes; HTML, CSS, JavaScript. The preview updates automatically as you type (with a short debounce). No Preview button to click.
Preset backgrounds are curated to match your role's color palette:

###🟣 Host presets: Purple Nebula, Hex Grid, Matrix Rain, Particles, Aurora
###🔵 Guest presets: Starfield, Blue Circuits, Matrix Rain, Particles, Aurora
###🟢 Viewer presets: Green Scan, Pulse Rings, Matrix Rain, Particles, Aurora

Appearance Settings Panel
A settings panel (⚙ button in the top bar) provides live controls for:

Canvas background color and image URL, with quick presets (Solid, Grid, Pure Black, Midnight Blue)
Window background color, title bar color, and border / accent color
Window corner radius
Drop shadow toggle and shadow color
Window opacity

All changes apply live without reloading any iframes.

## Export and Import
Your current layout and parameter configuration can be exported as a JSON file and imported back at any time. The JSON records the room name, user name, role, all toggled parameters per window, and the position, size, and maximized state of every window. Share a settings file with a collaborator so they can load an identical layout instantly.

There are no external JavaScript dependencies. The only external resources loaded at runtime are two Google Font families (Syne and DM Mono), which are used for the UI and monospace text respectively. If you want the file to work fully offline, replace those <link> tags with base64-embedded fonts or system font fallbacks.

## Customization for Developers

Changing the Default VDO.Ninja Server
The base URL is defined at the top of the script block:

const BASE_DEFAULT = 'https://vdo.ninja';
const BASE_PROXY   = 'https://proxy.vdo.ninja';

Replace these with your own self-hosted VDO.Ninja instance if you run one.

VDO.Ninja itself recommends Chrome for the best experience, and that recommendation applies here too.
